# SIMFOR_plotter_c

C++ библиотека для отображения двумерных графиков, трёхмерных поверхностей и наборов точек с помощью OpenGL и FreeGLUT. Вычислительное ядро вынесено в `plotter_core`; библиотека и демонстрационные программы собираются из каталога `plotter_c`.

## Возможности

- отображение нескольких графиков, поверхностей или наборов точек;
- настройка подписей осей и легенды, цветов, размеров линий и точек;
- переключение стилей графиков и поверхностей во время просмотра;
- вращение, перемещение и масштабирование камеры;
- вычисление выборок с проверкой диапазонов, шагов и неконечных значений;
- старый интерфейс наборов точек `initialization_p_many(double***)` сохранён для совместимости; предпочтителен интерфейс `initialization_points` с векторами.

## Зависимости

Для сборки нужны компилятор C++ с поддержкой C++11, GNU Make, `ar` и FreeGLUT с заголовками OpenGL.

В Debian/Ubuntu установите зависимости:

```sh
sudo apt-get update
sudo apt-get install g++ make freeglut3-dev
```

## Сборка

```sh
cd plotter_c
make
```

Команда собирает статическую библиотеку `libplotter.a` и примеры `test_2d`, `test_3d`, `test_points`, `test_core`. Для сборки вычислительных тестов без создания окна OpenGL:

```sh
make check
```

Очистка результатов сборки:

```sh
make clean
```

Для Windows с MinGW предусмотрен `Makefile_win`:

```sh
mingw32-make -f Makefile_win
mingw32-make -f Makefile_win check
```

Сборка использует C++11; флаги компилятора можно переопределить, например `make CXXFLAGS="-std=c++14 -O2 -Wall -Wextra"`.

## Подключение к своей программе

Подключите `plotter.h`, подготовьте функции и вызовите инициализацию GLUT, общих параметров окна и данных, затем `OpenGL()`. Пример функции:

```cpp
#include <cmath>
#include <string>
#include <GL/freeglut.h>
#include "plotter.h"

double f(double x) { return std::sin(x); }

int main(int argc, char **argv) {
    glutInit(&argc, argv);
    initialization_general(800, 600);
    std::string labels[] = {"sin(x)"};
    Set_Legend_Text(labels, 1);
    double (*functions[])(double) = {f};
    initialization_function(-5, 5, functions, 1);
    OpenGL();
}
```

Для поверхностей передайте функции вида `double f(double x, double y)`, включите режим поверхностей через `surface_mode(true)` и используйте `initialization_surface(x_min, x_max, y_min, y_max, functions, count)`.

Для точек новый интерфейс принимает вектор наборов; каждый внутренний вектор содержит координаты `{x, y, z}`:

```cpp
std::vector<std::vector<plotter_core::Coordinates>> sets = {
    {{0, 1, 0}, {1, 2, 0}},
    {{0, 2, 0}, {1, 3, 0}}
};
initialization_points(sets);
```

Клиентскую программу можно скомпилировать и слинковать с собранной библиотекой так:

```sh
g++ -std=c++11 client.cpp -Iplotter_c -Lplotter_c -lplotter -lGL -lglut -o client
```

Полные примеры настройки и использования находятся в `plotter_c/Инструкция.txt` и файлах `test_2d.cpp`, `test_3d.cpp`, `test_points.cpp`.

## Управление в окне

Регистр клавиш имеет значение.

| Клавиша | Действие |
| --- | --- |
| `u` | включить/выключить сглаживание линий |
| `o` | выбрать следующий набор |
| `i` | показать/скрыть все наборы |
| `g` | циклически сменить стиль графика или поверхности |
| `x`, `y`, `z` | вращать по соответствующей оси |
| `X`, `Y`, `Z` | вращать в обратном направлении |
| `+`, `-` | приблизить / отдалить |
| `w`, `s` | сдвиг по Y |
| `a`, `d` | сдвиг по X |
| `q`, `e` | сдвиг по Z |
| `r` | сбросить положение камеры |
| `l` | показать/скрыть легенду |
| `t` | показать/скрыть подписи осей |
| `n` | переключить сетку |
| `m` | переключить миллиметровый режим |

Для обычных графиков клавиша `g` переключает линии, точки и сочетание линий с точками. Для поверхностей она циклически меняет точки, линии с точками, линии и заливку.
